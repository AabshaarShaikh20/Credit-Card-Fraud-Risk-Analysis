# Credit Card Fraud Risk Analysis

This project presents an interactive Power BI dashboard for analyzing credit card fraud patterns, transaction amounts and risk levels. The dashboard provides a consolidated view of fraud-related indicators and allows users to explore transaction patterns across different fraud types, transaction categories, states, months and merchants.

The objective is to make fraud-related data easier to explore and to support data-driven risk monitoring.

# Key Dashboard Features
1. Fraud Overview: Displays fraud rate, fraudulent transaction count, critical-risk transaction count, and additional transaction indicators.
2. Fraud Type Analysis: Compares transaction amounts across fraud types and transaction categories.
3. Risk Distribution: Visualizes transaction amounts across low, medium, high, and critical risk levels.
4. State-wise Analysis: Compares fraudulent transaction counts across states.
5. Monthly Trend Analysis: Tracks changes in fraudulent transaction counts throughout the year.
6. Interactive Filters: Enables filtering by fraud type, state, and merchant name.
